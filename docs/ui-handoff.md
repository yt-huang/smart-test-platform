# Portal UI handoff v1

Chinese working product titled 智测平台 / Smart Test Platform. Dark navy compact sidebar, bright neutral canvas, teal primary action, readable typography, restrained charts and status badges. Responsive desktop-first with functional mobile nav. Navigation: 概览, 用例库, 测试计划, 执行记录, 资源池, Agent 管理, 系统设置. Header shows breadcrumbs, current user/role, logout. Login uses configured admin credentials and no hardcoded password.

Dashboard presents live metrics, pass/fail trend, latest executions, resource capacity, first-run guidance if empty. Cases have text/platform/status filtering, validated create/edit form and human approval action. Plans select approved cases and capabilities; trigger run via real API. Runs refresh while active, detail shows steps/error/fingerprint/logs/evidence and JUnit download; handle auth for media using fetch/blob. Resources show real agent/device state and clear empty state; no pretend device screen. Agent key creation displays one-time key and connector commands, revoke functional. Settings shows integrations/dependencies and user management for admin. All views have loading, empty, error, success and disabled states; destructive deletes/revoke ask inline confirmation; failure toasts include server message. Do not hide missing integration behind decorative buttons. Preserve form input on API failures. Match `docs/implementation-handoff.md` contract.
